# Maintain Architecture & Developer Guide Rule

Whenever any modification, addition, refactor, or deletion is made to the codebase (including backend models, schemas, engines, API routes, database configuration, or frontend components and services):

1. You MUST update `ARCHITECTURE_AND_DEVELOPER_GUIDE.md` to reflect the changes.
2. Ensure all architecture diagrams, endpoint documentation, engine descriptions, database ER schemas, and component trees remain 100% accurate and up-to-date.
